# Contributing

Use Windows with the .NET 10 SDK. Run build.ps1 and test.ps1 before submitting a pull request. Desktop tests open native windows and require an interactive Windows session with Sightquill closed. CI runs the model suite and builds the Windows application; local desktop verification is required for UI changes.

Keep changes focused. Include screenshots for UI changes and a minimal share code for import/rendering bugs. Do not commit artifacts, game binaries, SDK downloads, user settings, credentials or signing certificates. Contributions are made under the project's MIT license.
