# Sightquill 0.6.1

Fixes Valorant imports whose odd-width lines or center dots appeared shifted relative to even-width layers. All layers now share the same aiming center before scaling and animation. Existing saved 0.6 profiles receive the correction automatically; no reimport is needed.

Regression coverage includes the two reported codes, normal and doubled size, and resting, intermediate and full animation states. Desktop rendering and core tests pass.

## Downloads

- Windows x64 installer: Sightquill-Setup-0.6.1-win-x64.exe
- Portable archive: Sightquill-0.6.1-win-x64.zip
- Integrity checks: Sightquill-0.6.1-SHA256SUMS.txt

Both packages include the .NET runtime and optional How to Fish companion. Close Sightquill before updating. Existing profiles and preferences are retained. The installer remains unsigned.
