# Sightquill 0.6.0

First public release with a per-user Windows installer and portable ZIP.

- 24 presets, color wheel, profiles and physical-pixel scaling.
- Transparent PNG, Valorant and CS:GO / CS2 imports; JSON and PNG export.
- Valorant per-layer movement/firing simulation and upper-branch fade.
- Optional How to Fish companion included; setup remains opt-in.
- Reopening the application restores its existing editor window.

Windows x64. The .NET runtime is included. This release is unsigned. Animation is input-based, not live weapon accuracy. Settings are retained on uninstall; remove the game companion separately through Set up if desired.

Download the Setup EXE for installation, or the full ZIP for portable use. SHA256SUMS lists checksums for both packages.
